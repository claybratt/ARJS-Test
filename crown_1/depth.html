Realtime Webcam Depth Map

This demo captures your webcam, runs monocular depth estimation in the browser, and draws a live depth map. It estimates relative depth from a normal RGB camera, so it is useful for effects and interaction, but it is not the same as true hardware-measured depth.

Tips

Reduce input width or FPS cap if the page feels slow.

Browsers typically require https:// or localhost for webcam access.

The grayscale output is normalized per frame: brighter and darker regions represent relative depth structure, not guaranteed metric distance in meters. That makes it great for blur, parallax, masking, and interaction demos.
